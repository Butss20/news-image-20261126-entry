A deterministic Node 22 program that draws a 1024x1024 newspaper front page summing up Thursday 26 November 2026: Lille stun Bayern on a big Champions League night, Taiwan answers the U.S. tariff plan, oil holds near $95 as Gulf strikes widen, Thanksgiving in America, Macy's 100th parade faces storm winds, and AI-bubble fears spread on Wall Street. Standard library only — no network, no fonts, no timestamps — so two runs produce byte-identical PNGs. The page is drawn pixel by pixel with an in-code 5x7 bitmap font and a hand-rolled PNG encoder.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The image is written to `out/entry.png`.
